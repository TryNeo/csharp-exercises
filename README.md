## Acerca del repositorio

Aquí reúno mis ejercicios de **C#**, desde programas sencillos de consola hasta ejercicios de orientación a objetos, interfaces y genéricos. Utilizo **.NET** para compilar y ejecutar mis soluciones.

## Contenido

| Área | Temas |
| :--- | :--- |
| **Fundamentos** | Variables, tipos de datos, operadores y conversiones |
| **Lógica** | Condiciones, ciclos y resolución de problemas |
| **Métodos** | Parámetros, valores de retorno y sobrecarga |
| **Colecciones** | Arreglos, listas, diccionarios y conjuntos |
| **Objetos** | Clases, propiedades, encapsulación y herencia |
| **Interfaces y genéricos** | Contratos, tipos reutilizables y restricciones con `where` |
| **Consultas** | Filtros, proyecciones y agrupaciones con LINQ |
| **Archivos y JSON** | Lectura, escritura, serialización y deserialización |
| **Asincronía** | Introducción a `Task`, `async` y `await` |

## Organización

Cada ejercicio tendrá su propia carpeta, identificada con un número y un nombre descriptivo, junto con su proyecto de consola y los archivos que necesite.

**Ejemplos de nombres:** `001-hola-csharp`, `002-operaciones-aritmeticas`, `003-condiciones-y-ciclos`.
