## Acerca del repositorio

Este repositorio documenta mi aprendizaje de **C# a través de los ejercicios de [Exercism](https://exercism.org/)**. Cada solución es una oportunidad para practicar, analizar problemas, experimentar con el lenguaje y escribir código más claro y mantenible.

Los enunciados y las pruebas de los desafíos provienen de Exercism; las implementaciones aquí publicadas representan mi práctica y mis propias soluciones.

## Objetivos

- Fortalecer los fundamentos del lenguaje y la resolución de problemas.
- Aplicar conceptos de programación orientada a objetos.
- Practicar el uso de métodos, colecciones, patrones y características modernas de C#.
- Mejorar la legibilidad y la estructura del código mediante la práctica constante.
- Comprobar el comportamiento de las soluciones con pruebas automatizadas.

## Temas de práctica

Los ejercicios permiten trabajar progresivamente distintos conceptos, entre ellos:

| Área | Temas |
| :--- | :--- |
| **Fundamentos** | Variables, tipos de datos, operadores, conversiones y constantes |
| **Control de flujo** | Condicionales, `switch`, bucles y patrones |
| **Métodos** | Parámetros, valores de retorno y sobrecarga |
| **Cadenas y colecciones** | `string`, arreglos, listas y diccionarios |
| **Orientación a objetos** | Clases, propiedades, encapsulación, herencia e interfaces |
| **Genéricos** | Tipos reutilizables y restricciones |
| **LINQ** | Filtrado, proyecciones y agrupaciones |
| **Otros conceptos** | Excepciones, fechas, archivos y asincronía, según los ejercicios abordados |

> Los temas describen el alcance de aprendizaje del repositorio; no indican que todos los ejercicios estén completados.

## Organización

Cada ejercicio se guarda en una carpeta independiente, con un nombre descriptivo relacionado con el desafío de Exercism. Cuando corresponda, se conservan los archivos de proyecto y las pruebas.

**Ejemplo ilustrativo de estructura:**

```text
csharp-exercises/
├── README.md
├── 001-lucians-luscious-lasagna/
│   └── ...
├── 002-interest-is-interesting/
│   └── ...
└── ...
```

Los nombres anteriores son ejemplos de organización, no un listado de ejercicios completados.

## Ejecutar las pruebas

Para trabajar con los ejercicios localmente, es necesario tener instalado el **SDK de .NET** compatible con el track de C# de Exercism.

Desde la carpeta del ejercicio, ejecuta:

```bash
dotnet test
```

Para volver a ejecutar las pruebas automáticamente al modificar los archivos:

```bash
dotnet watch test
```

**Nota:** algunos ejercicios de Exercism incluyen pruebas inicialmente deshabilitadas con `Skip`. Se pueden habilitar progresivamente siguiendo las instrucciones del propio ejercicio.
